# S3 Audit Archive (`services/s3.md`)

- Provision a dedicated S3 bucket (`aws_s3_bucket`) for NDJSON audit batches (`force_destroy = true` recommended so `destroy.sh` can remove the bucket after versioned audit objects and delete markers are written).
- Enable bucket versioning (`aws_s3_bucket_versioning` with `status = "Enabled"`).
- Enable default server-side encryption (`aws_s3_bucket_server_side_encryption_configuration`) using `sse_algorithm = "aws:kms"` and `kms_master_key_id = kms.audit_arn`.
- Block all public access (`aws_s3_bucket_public_access_block`) with all four flags (`block_public_acls`, `block_public_policy`, `ignore_public_acls`, `restrict_public_buckets`) set to `true`.
- Configure the Audit Archiver Lambda with `AUDIT_BUCKET = <bucket_name>` and `AUDIT_PREFIX = "ledger-audit/"` (`manifest.audit.prefix = "ledger-audit/"`).
- `clearledger-audit-archiver` writes NDJSON batches to `s3://<bucket_name>/ledger-audit/batch-<first_seq:08d>-<last_seq:08d>-<16_char_sha256_hex>.ndjson`, where `<first_seq:08d>` and `<last_seq:08d>` are the 8-digit zero-padded first and last `clearledger.outbox.seq` in the batch, the NDJSON lines inside each batch are ordered by strictly ascending `clearledger.outbox.seq`, and `<16_char_sha256_hex>` is the first 16 lowercase hexadecimal characters of the SHA-256 digest of the object's raw bytes.
- During `deploy.sh` data-plane convergence, reconcile the S3 audit bucket against `clearledger.outbox` so that:
  - No stray objects exist outside the `ledger-audit/` prefix.
  - Any S3 batch object under `ledger-audit/` whose key does not match `ledger-audit/batch-<first_seq:08d>-<last_seq:08d>-<16_char_sha256_hex>.ndjson` (with `<16_char_sha256_hex>` matching the SHA-256 digest of its raw bytes and `<first_seq:08d>`..`<last_seq:08d>` matching the first and last `clearledger.outbox.seq` of its records), or whose records are not ordered by strictly ascending `clearledger.outbox.seq`, or that contains invalid JSON, an orphan `eventId` absent from `clearledger.outbox`, a tampered record whose JSON payload diverges from `clearledger.outbox.payload`, an `eventId` whose `clearledger.outbox.archived_at` is `NULL`, or a duplicate `eventId` already present in another valid batch is purged.
  - Any `clearledger.outbox` row whose `event_id` is not present in the surviving valid S3 batch objects under `ledger-audit/` has `archived_at` reset to `NULL` before invoking `audit_archiver`, ensuring every committed event in `clearledger.outbox` appears **exactly once** across `s3://<bucket_name>/ledger-audit/batch-*.ndjson` with its exact canonical JSON payload, valid batch key digest, and ascending `seq` order.
